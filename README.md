# 方块原野 · Blocklands

使用原生 HTML、CSS、JavaScript 编写的简单 2D 方块沙盒游戏。无需安装依赖，没有构建步骤，也没有外部图片或网络资源。

## 运行

直接打开 `index.html` 即可游玩。开发时推荐在仓库目录运行：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

然后用浏览器访问该服务。需要支持 Canvas、Pointer Events 和 localStorage 的现代浏览器。

## 操作

- A / D 或左右方向键：移动；空格、W 或上方向键：跳跃。
- 鼠标左键：挖掘；右键：放置；操作距离为五格。
- 1—5、鼠标滚轮或点击快捷栏：选择草方块、泥土、石头、木材、树叶。
- 触屏：使用屏幕方向键和跳跃键，切换挖掘/放置模式后点按世界。
- 点击“保存世界”保存；游戏每分钟也会自动保存。重新加载会恢复最近保存的世界和位置。
- “新世界”会在确认后生成随机世界；下一次保存会覆盖原存档。

草、泥土、石头与木材具有碰撞；树叶可以穿过。游戏采用无限方块的自由创造模式，没有怪物或合成系统。

## 文件

- `index.html`：界面与画布。
- `style.css`：响应式界面与触屏控制样式。
- `game.js`：地形生成、物理、绘制、编辑和存档。

存档仅保存在当前浏览器的 localStorage 中，不会上传服务器；清理浏览器数据会删除存档。私密浏览或禁用存储时可能无法保存，游戏会显示提示。
